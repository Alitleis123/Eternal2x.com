Help

Installation guides and troubleshooting.

Troubleshooting

Common issues and their solutions.

The plugin doesn't appear in Resolve ▼
Make sure you ran the installer and it completed successfully. The plugin should appear at Workspace → Scripts → Eternal2x. If it's not there, restart Resolve. If it still doesn't appear, re-run the installer.
"Plugin folder not configured" ▼
The plugin cannot find the folder you extracted it to. The usual cause is moving or renaming that folder after installing, since the config records its path. Re-run the installer from the new location.
"Could not reach Resolve" ▼
The panel is not running inside DaVinci Resolve. Open it from Workspace → Scripts → Eternal2x, not by double-clicking the Lua file.
Rendering is slow on long clips ▼
Every frame has to be read and every missing in-between generated, so the time scales with the length of the clip on your timeline. Only the part of the file the clip uses is processed, so trimming it short makes it quicker. Ten seconds of 1080p takes roughly ten to twenty seconds depending on the Quality setting. Resolve stays usable throughout, and Analyse is much quicker if you only want to see what a clip contains.
Analyse says there is nothing to do ▼
The clip has no duplicated frames, so there is nothing to recover. It is either live action or animation already drawn on 1s. Smoothing it would only invent motion that was never there, so Eternal2x stops instead.
The upscale was skipped ▼
Super Scale is a DaVinci Resolve Studio feature. On the free edition Eternal2x tells you it was skipped rather than silently leaving it out. De-duplication and smoothing still run.
Resolve would not import the result ▼
The render still finished. The panel prints where it is, so you can drag it into your media pool. Setting Output to Image sequence avoids this, since Resolve always imports those.
Progress seems stuck ▼
Press Refresh Progress. If a run was interrupted, press Reset to clear it. For anything else, email the panel's status text and the .eternal2x_last_run.log file from the plugin folder.
"python" is not recognised, or the installer window does not open ▼
Install Python 3.8 or newer from python.org. On Windows, tick Add python.exe to PATH in its installer, then open a new terminal. If the installer window still does not open, your Python was built without Tk. Use the manual install commands further down this page instead. They do the same job without a window.
"No clip under the playhead" ▼
Eternal2x works on the clip under the playhead, since Resolve does not tell scripts which clip is selected. Move the playhead over the clip, then press Use Clip at Playhead in the panel.

Windows Guide

Extract, run the installer, restart Resolve.

1

Download the plugin

Go to the Download page and grab the Windows zip.

2

Extract the zip

Right-click the downloaded file and select Extract All. Put it somewhere permanent, not your Downloads folder.

Do not move this folder after installing. If you do, re-run the installer.
3

Run the installer

You need Python 3.8 or newer from python.org. Open the extracted folder, type cmd in the address bar and press Enter, then run:

python Installer\gui_installer.py

Click the Install button and wait for it to finish. The installer will:

  • Install the required Python packages
  • Copy the plugin into DaVinci Resolve
  • Write the configuration file
4

Open in Resolve

Restart DaVinci Resolve, then go to:

Workspace → Scripts → Eternal2x

Manual install (alternative)

If the installer window does not open, run these from the same folder instead.

pip install numpy opencv-python
python Installer/install_eternal2x.py

Then restart Resolve.

macOS Guide

Same process. Extract, install, restart Resolve.

1

Download the plugin

Go to the Download page and grab the macOS zip.

2

Extract the zip

Double-click the zip file to extract it. Move the folder somewhere permanent, like your home directory or Applications.

3

Run the installer

You need Python 3.8 or newer from python.org. Open Terminal and run:

cd ~/path/to/eternal2x-mac
python3 Installer/gui_installer.py

Click Install and wait for it to finish. Works on both Apple Silicon and Intel Macs.

4

Open in Resolve

Restart DaVinci Resolve, then go to:

Workspace → Scripts → Eternal2x

Manual install (alternative)

pip3 install numpy opencv-python
python3 Installer/install_eternal2x.py

Then restart Resolve.

How to Use

Analyse to see what you have, then rebuild it.

1

Put the playhead on a clip

Move the playhead over the clip you want on your timeline, then open Workspace → Scripts → Eternal2x. The panel shows the clip it picked up. Analyse and Smooth Clip always use the clip under the playhead when you press them, and Use Clip at Playhead shows you which one that is.

2

Analyse

Click Analyse. Eternal2x reads the clip and reports what it found, for example 1438 frames, 719 unique drawings (719 held, 50%). Animated on 2s. Nothing is changed, so this is safe to run on anything. If a clip has no duplicated frames it says so and stops.

3

Choose your settings

Quality trades speed for detail, with Better suiting most work. Leave Hold pattern on Auto detect unless a clip has unusual timing. Output defaults to a lossless image sequence, which Resolve always imports. Upscale 2x applies Super Scale to the result, and turning off Interpolate removes the duplicates without generating in-betweens. Settings are remembered between sessions.

4

Smooth Clip

Click Smooth Clip. The render runs in the background with a progress bar, so Resolve stays usable. When it finishes, the rebuilt clip is imported with 2x Super Scale applied and added to the end of your timeline, at the same length and frame rate as the clip you trimmed. Only that part of the file is processed.

What to expect

How the result should look.

Held poses stay still

A drawing held deliberately keeps its full length instead of drifting. Only the animation timing is smoothed.

Cuts stay hard

Eternal2x never blends across a scene change, which would show both shots at once.

Very fast motion may stay stepped

This is deliberate. Past a certain speed the areas a drawing uncovers exist in only one frame, so no in-between can be reconstructed. Eternal2x holds a real drawing rather than producing a smeared one.

Staying up to date

Updates arrive on their own.

Automatic

Eternal2x checks for a new version each time the panel opens. If one is available it is downloaded, verified against a checksum, and applied. Restart Resolve afterwards to load it. You can turn this off with the Auto-update checkbox.

On demand

Press Check for Updates at any time. If nothing has changed it says so and leaves your install alone. A failed check never stops you working, it is reported and skipped.

Re-running the installer

Only needed if you move or rename the plugin folder, since the config records where it lives. Updates themselves do not require it.
