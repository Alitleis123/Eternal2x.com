Troubleshooting

Common issues and their solutions.

The plugin doesn't appear in Resolve ▼
Make sure you ran the installer and it completed successfully. The plugin should appear at Workspace → Scripts → Eternal2x. If it's not there, restart Resolve. If it still doesn't appear, re-run the installer. If Resolve says you need Studio when you open it, you are on the free edition, which blocks script panels since Resolve 19.1.
Clicking Eternal2x does nothing ▼
Open Workspace → Console. If it says UI script not found or Missing repo_root, the plugin folder was moved, renamed or deleted after installing, since the config records its path. Re-run the installer from where the folder is now. The panel's "Plugin folder not configured" means the same thing.
"Could not reach Resolve" ▼
The panel is not running inside DaVinci Resolve. Open it from Workspace → Scripts → Eternal2x, not by double-clicking the Lua file.
Rendering is slow on long clips ▼
Every frame has to be read and every missing in-between generated, so the time scales with the length of the clip on your timeline. Only the part of the file the clip uses is rebuilt, so trimming it short makes it quicker, though a cut late in a long file is still decoded up to its start first, shown as Seeking. On Windows the in-betweens are drawn on the GPU through DirectML, and ten seconds of 1080p takes roughly ten to twenty seconds. Where the CPU has to draw them it is about ten times slower. With Grainy source on, the clip is read twice while Analyse measures its grain. Resolve stays usable throughout, and Analyse is much quicker if you only want to see what a clip contains.
"No duplicate frames. This clip is already on 1s." ▼
Analyse found nothing to do. The clip has no duplicated frames, so there is nothing to recover. It is either live action or animation already drawn on 1s. Smoothing it would only invent motion that was never there, so Eternal2x stops instead. If the panel says instead that every frame differs but the differences look like grain, tick Grainy source and analyse again. Leave it off for clean animation, where it can merge fine real changes.
"...has a variable frame rate" ▼
Phone and screen recordings often space their frames unevenly. Eternal2x writes every frame for the same time, so such a clip would come out a different length and drift against its audio, and it stops instead. Render the clip to a constant frame rate first, from Resolve's Deliver page or with ffmpeg -i clip.mp4 -r 24 clip_cfr.mp4 at your timeline's rate, then use that.
The upscale was skipped ▼
Super Scale is a DaVinci Resolve Studio feature. If the panel says the upscale was not applied, check that Studio is activated. De-duplication and smoothing still run.
Resolve would not import the result ▼
The render still finished. The panel prints where it is, so you can drag it into your media pool. Setting Output to Image sequence usually avoids this, since Resolve imports those most reliably.
Progress seems stuck ▼
Press Refresh Progress. If a run was interrupted, press Reset to clear it. For anything else, email the panel's status text and the .eternal2x_last_run.log file from the plugin folder.
"python" is not recognised, or the installer window does not open ▼
Install Python 3.14 from python.org. Any version from 3.10 to 3.14 works. 3.15 is too new for the AI runtime, and Eternal2x would keep every drawing as drawn. On Windows, tick Add python.exe to PATH in its installer, then open a new terminal. If the installer window still does not open, your Python was built without Tk. Use the manual install commands further down this page instead. They do the same job without a window.
"No clip under the playhead" ▼
Eternal2x works on the clip under the playhead, since Resolve does not tell scripts which clip is selected. Move the playhead over the clip, then press Use Clip at Playhead in the panel.

Windows Guide

Extract, run the installer, restart Resolve.

1

Download the plugin

Go to the Download page and grab the Windows zip.

2

Extract the zip

Right-click the downloaded file and select Extract All. Put it somewhere permanent, not your Downloads folder.

Do not move this folder after installing. If you do, re-run the installer.
3

Run the installer

You need Python 3.10 to 3.14. Get Python 3.14 from python.org, not 3.15, which is too new for the AI runtime. Open the extracted folder, then the eternal2x-win folder inside it, the one that contains Installer. Type cmd in the address bar and press Enter, then run:

python Installer\gui_installer.py

Click the Install button and wait for it to finish. The installer will:

  • Install the required Python packages
  • Copy the plugin into DaVinci Resolve
  • Write the configuration file
4

Open in Resolve

Restart DaVinci Resolve, then go to:

Workspace → Scripts → Eternal2x

Manual install (alternative)

If the installer window does not open, run these from the same folder instead.

python -m pip install numpy opencv-python
python Installer/install_eternal2x.py

Then restart Resolve.

macOS Guide

Same process. Extract, install, restart Resolve.

1

Download the plugin

Go to the Download page and grab the macOS zip.

2

Extract the zip

Double-click the zip file to extract it. Move the folder somewhere permanent, like your home directory or Applications.

3

Run the installer

You need Python 3.10 to 3.14, or 3.10 to 3.13 on an Intel Mac, where the AI runtime stops at 3.13. Get Python 3.14 or Python 3.13 from python.org. Open Terminal and run:

cd ~/path/to/eternal2x-mac
python3 Installer/gui_installer.py

Click Install and wait for it to finish. Works on both Apple Silicon and Intel Macs.

4

Open in Resolve

Restart DaVinci Resolve, then go to:

Workspace → Scripts → Eternal2x

Manual install (alternative)

python3 -m pip install numpy opencv-python
python3 Installer/install_eternal2x.py

Then restart Resolve.

How to Use

Analyse to see what you have, then rebuild it.

1

Put the playhead on a clip

Move the playhead over the clip you want on your timeline, then open Workspace → Scripts → Eternal2x. The panel shows the clip it picked up. Analyse and Render always use the clip under the playhead when you press them, and Use Clip at Playhead shows you which one that is.

2

Analyse

Click Analyse. Eternal2x reads the clip and reports what it found, for example 1438 frames, 719 unique drawings (719 held, 50%). Animated on 2s. It also marks the drawings on the clip, replacing only the markers it placed before. If a clip has no duplicated frames it says so and places none.

3

Choose your settings

The in-betweens are drawn by the RIFE network, so moving characters stay solid. Its first run downloads about 50 MB. Leave Hold pattern on Auto detect unless a clip has unusual timing. Output defaults to a lossless image sequence, which Resolve imports most reliably. Renders are 8-bit RGB, so transparency and 10-bit colour are not kept. Upscale 2x applies Super Scale to the result, which only shows on a timeline bigger than the clip, such as 3840x2160 for 1080p footage. Turning off Interpolate skips the in-betweens and keeps every drawing on its original frame. Tick Grainy source for film grain, which otherwise makes every held frame look new. Settings are remembered between sessions.

4

Mark the frames, then Render

Analyse also puts a marker on the clip at every drawing it found. Delete a marker to leave its frame out, even if it moved, or select the clip and press M to mark a frame it missed. Threshold sets how big a change Analyse counts, and analysing again replaces only its own markers. Every marker on the clip counts, but not the ones on the timeline's ruler. You can also skip Analyse and mark the frames yourself.

Click Render. It keeps every marked frame as drawn and draws every frame between two markers fresh. With no markers on the clip, it uses the drawings Eternal2x finds. The render runs in the background with a progress bar and the time left, so Resolve stays usable. When it finishes, the rebuilt clip is imported with 2x Super Scale applied and placed on the track above the original, starting on the same frame, at the same length and frame rate. It uses the lowest track that is empty there, or a new track named Eternal2x, so none of your clips are covered. Only the part of the file you trimmed is rebuilt.

Show Original switches the smoothed clip off so the original shows through, and Show Eternal2x switches it back. Show in Folder opens where the render was saved.

What to expect

How the result should look.

Held poses stay still

A drawing held deliberately keeps its full length instead of drifting. Only the animation timing is smoothed.

Cuts stay hard

Eternal2x never blends across a scene change, which would show both shots at once.

Nothing was smoothed

The first render installs the network's runtime and downloads its model, so it needs a connection once. Without one, every drawing is kept as drawn rather than filled in some other way, since warping pixels doubles lines on drawn animation. The status says why. Smooth again once you are online.

Staying up to date

Updates arrive on their own.

Automatic

Eternal2x checks for a new version each time the panel opens. If one is available it is downloaded, verified against a checksum, and applied. Restart Resolve afterwards to load it. You can turn this off with the Auto-update checkbox.

On demand

Press Check for Updates at any time. If nothing has changed it says so and leaves your install alone. A failed check never stops you working, it is reported and skipped. An update that cannot finish is undone, so you keep the version you had.

Re-running the installer

Needed once when updating from 0.3.1 or earlier. Those versions put the launcher where Resolve lists it only on the Fusion page, or on Windows not at all. After that, only if you move or rename the plugin folder, since the config records where it lives.
