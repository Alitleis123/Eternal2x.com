Smooth out choppy animation.

Hand-drawn animation, from anime to cartoons, often holds each drawing for two or three frames, so it moves in steps. Eternal2x draws the frames in between, right inside DaVinci Resolve, so it plays smooth at the full frame rate.

Download, free How to install

How it works

Open the panel from Workspace, Scripts and put the playhead on a clip. This is the path it takes, and the film shows all of it in 21 seconds.

  1. Input Your clip Anything on the timeline, on 2s or 3s
  2. Analyse Finds the real drawings Tells you how it's animated before it changes a thing
  3. Smooth Clip Draws every in-between RIFE 4.25 on your own machine, Resolve stays usable
  4. Output Lands on the track above Same frame and length. Show Original flips between them
