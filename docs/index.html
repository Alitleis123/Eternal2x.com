For DaVinci Resolve Studio

Drawn on twos. Played on ones.

Eternal2x finds the real drawings in a held anime shot and draws the frames in between, then puts the result on the track above your clip.

Download, free How to install

See it in Resolve

Analyse the clip, press Smooth Clip, and the result lands on the track above, lined up with the original. 21 seconds, sound on.

What you need

One installer sets up the rest. The first render downloads the AI model, about 50 MB.

Resolve

DaVinci Resolve Studio 18 or newer

The free edition blocks script panels since 19.1.
System

Windows 10 or 11, or macOS 12 or newer

Windows draws the in-betweens on the GPU where it can.
Python

3.10 to 3.14

Older Macs need an older one. See the Mac guide.
