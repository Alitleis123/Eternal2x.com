In-betweens on the CPU, upscale with Super Scale. Python 3.14 needs macOS 14 and Apple Silicon. The Mac guide lists the rest.

Coming from 0.3.1 on Windows? Download again and run the installer once more. 0.3.1 put the panel in a folder Resolve never reads, so it could not open or update itself. On a Mac, run the installer again too, so the panel shows on every page and not only Fusion.

Install in three steps

You need DaVinci Resolve Studio 18 or newer and Python 3.10 to 3.14. Python 3.15 is too new for the AI runtime. The help page walks through every click.

  1. Extract

    Unzip it somewhere permanent, not your Downloads folder. The panel remembers where it lives, so moving it later means running the installer again.

  2. Install

    From the folder that contains Installer, run python Installer/gui_installer.py, or python3 on macOS, and click Install.

  3. Open

    Restart Resolve and choose Workspace, Scripts, Upflow2x. After that it updates itself.
